Hand the job to an AI agent

    
Give Claude Code, Codex or any agent a Markdown audio list and ask it to produce the audio.
       The agent should read README.md and AGENTS.md in the project folder first;
       they describe the list format and the rules.

    
Core commands

    
./audiogen.sh inspect LIST.md --lang es --json
./audiogen.sh generate LIST.md --lang es -o out/
./audiogen.sh verify LIST.md --lang es -o out/

    
Use Copy CLI command on the Generate tab to get the exact command for what you configured.

    
HTTP API

    
Base URL:  · interactive docs (/api/docs)

    
Every endpoint takes a lang code and either a file path or the Markdown text.
       Typical flow: POST /api/inspect, then POST /api/generate, poll GET /api/jobs/{id}.
